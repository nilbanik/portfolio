# 🌐 Nilesh Banik — Personal Portfolio Website

A responsive, modern personal portfolio website showcasing my software development skills, frontend projects, background, and contact information.

---

## 📌 Features & Sections

* **Profile Section:** Quick introduction, resume download link, contact button, and direct links to GitHub and LinkedIn.
* **About Me:** Academic background (B.Tech in Mechanical Engineering, IIEST Shibpur) and experience summary.
* **Experience & Skills:** Categorized breakdown of technical proficiencies:
  * **Frontend:** HTML, CSS, JavaScript, Bootstrap
  * **Backend & Tools:** Python, C, MySQL, Git
* **Projects Showcase:** Grid showcase of recent projects with direct links to GitHub repositories and live deployments.
* **Contact Section:** Direct email trigger and LinkedIn profile links.
* **Responsive Design:** Custom media queries (`@media screen`) supporting mobile (<600px), tablet (<1200px), and desktop viewports, complete with a collapsible hamburger navigation menu.

---

## 🛠️ Built With

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom layout design, Flexbox, smooth transitions, and glassmorphism styling (`backdrop-filter`).
* **JavaScript:** DOM manipulation for dynamic hamburger menu toggling.
* **Google Fonts:** Poppins typeface.

---

## 📁 File Structure

* `portfolio.html` — Main HTML markup
* `style.css` — Core styling and layout rules
* `mediaqueries.css` — Responsive breakpoints (mobile, tablet, desktop)
* `script.js` — Navigation drawer and menu logic
* `assets/` — Icons, project previews, profile photos, and resume
  
---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `portfolio.html` directly in any web browser (or use the VS Code Live Server extension).
